# AGENTS.md

## Purpose
This repository is a training environment for Agentic Software Engineering.

## General instructions
- Prefer small, reviewable changes.
- Read the relevant documentation before modifying code.
- Do not change unrelated files.
- State assumptions when requirements are ambiguous.
- Add or update tests for behavioral changes.
- Run the relevant tests before considering a task complete.
- Do not weaken tests merely to make them pass.
- Never commit secrets, credentials or tokens.
- Preserve backwards compatibility unless the task explicitly requires a breaking change.

## Definition of done
A task is complete when:
1. the requested behavior is implemented;
2. acceptance criteria are satisfied;
3. relevant tests pass;
4. linting/static checks pass where configured;
5. the diff contains no unrelated changes;
6. documentation is updated when necessary.

## Training note
Some exercises intentionally contain defects or incomplete requirements. Do not proactively solve exercises that have not been assigned.
