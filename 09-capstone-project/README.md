# 09 — Projet fil rouge / Capstone

## Objectif
Mettre en œuvre l’ensemble du workflow d’Agentic Software Engineering sur un projet logiciel réaliste.

## Workflow cible

```text
issue / besoin
  ↓
spécification + critères d’acceptation
  ↓
choix et orchestration des agents
  ↓
branches / worktrees
  ↓
implémentation
  ↓
tests + Ruff + CI
  ↓
diff + pull request
  ↓
revue
  ↓
intégration
```

## Résultat attendu
Le participant doit être capable de concevoir et superviser le système de travail, plutôt que de simplement demander à une IA de générer du code.
