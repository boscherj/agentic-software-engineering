# 05 — Context Engineering

## Objectif
Apprendre à fournir aux agents le contexte nécessaire pour produire des changements fiables et cohérents.

## Thèmes
- contexte du repository ;
- `AGENTS.md` ;
- instructions spécifiques aux outils ;
- documentation et conventions ;
- spécifications et critères d’acceptation ;
- contexte minimal versus surcharge de contexte.

## TP
Améliorer le contexte du projet fil rouge puis mesurer son influence sur le travail des agents.
