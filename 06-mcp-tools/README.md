# 06 — MCP et outils

## Objectif
Comprendre comment un agent étend ses capacités au-delà du code grâce aux outils et au Model Context Protocol.

## Thèmes
- modèle outil/appel/résultat ;
- MCP ;
- serveurs et clients ;
- accès aux systèmes externes ;
- permissions ;
- sécurité et principe du moindre privilège.

## TP
Connecter un outil contrôlé au workflow du projet fil rouge et observer son utilisation par l’agent.
