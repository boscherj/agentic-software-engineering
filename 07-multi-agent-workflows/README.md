# 07 — Workflows multi-agents

## Objectif
Organiser plusieurs agents travaillant en parallèle sans perdre le contrôle du repository.

## Thèmes
- décomposition du travail ;
- branches ;
- Git worktrees ;
- isolation des agents ;
- parallélisation ;
- conflits et intégration ;
- rôle de l’ingénieur comme orchestrateur.

## TP
Faire travailler plusieurs agents sur des tâches distinctes du projet fil rouge puis intégrer les résultats.
